# 🏭 Smart Factory IIoT Monitoring System
**Система промышленного мониторинга цеха: сбор телеметрии, компьютерное зрение, Excel-отчетность и Telegram-оповещения.**

Программный Edge-шлюз на Python для объединения разнородного производственного оборудования в единую систему диспетчеризации и контроля аварий 24/7.

## 🏗 Архитектура решения

```text
[ПЛК / Станок (Modbus TCP)] ──┐
[Весы / Датчики (RS-232/COM)] ┼──► [Factory Hub (Python)] ──► [MQTT Broker (Mosquitto)]
[Сервер цеха (OPC UA)]       ─┤                                      │
[Камера ОТК (OpenCV+YOLO11)] ─┘                                      ▼
                                                ┌────────────────────┴────────────────────┐
                                                ▼                                         ▼
                                      [SQLite Telemetry DB]                     [AlertManager (TG/SMTP)]
                                                │                               (Алерты + Антиспам)
                                                ▼
                                      [Excel Shift Reports]
                                      (Сменные отчеты pandas)
```

## 🚀 Возможности системы
* **Мультипротокольный опрос (`pymodbus`, `paho-mqtt`, `asyncua`, `pyserial`):** чтение регистров ПЛК (включая `INT16` со знаком, `FLOAT32`, битовые маски аварий), прием данных по MQTT, OPC UA и COM-портам.
* **Компьютерное зрение на линии (`OpenCV` + `YOLO11`):** детекция и подсчет продукции на конвейере в реальном времени.
* **Уведомления об авариях (`Telegram` + `SMTP`):** мгновенные оповещения о перегреве и потере связи (`OFFLINE`), поддержка SOCKS5-прокси, встроенный антиспам (`cooldown`) и автоуведомление о восстановлении нормы.
* **Аналитика и отчеты (`SQLite` + `pandas` + `openpyxl`):** запись истории телеметрии и автоматическая генерация оформленных Excel-отчетов по итогам смены.
* **Готовность к деплою (`Docker`):** полная конфигурация для запуска инфраструктуры одной командой (`docker compose up`).

## ⚡ Быстрый старт (Локально)
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Скопируйте `.env.example` в `.env` и укажите параметры подключения.
3. Запустите имитатор оборудования и главный диспетчер:
   ```bash
   python virtual_plc.py
   python factory_hub.py
   ```
